01 / Built for the repeat

Just enough control to make clicks predictable.

Keep the setup straightforward: choose what to click, how often, and when the run should stop. Your settings are saved for next time.

A / Timing

Fixed or varied intervals

Use a steady delay or add a millisecond variance around your base interval for less uniform timing.

B / Control

A hotkey that stays global

Start and stop clicking with a configurable key or key combination, even while the app is hidden to the system tray.

C / Limits

Stop when the job is done

Let clicks continue until you press the hotkey, or set a click count and have the run stop automatically.

02 / Start in seconds

Set it up. Move into place. Press your key.

Clicks are sent at the current mouse pointer position, so move the pointer to the target before starting.

Step 01

Choose click and timing

Select left or right click, then set a fixed or randomized delay.

Step 02

Pick a stop condition

Use the hotkey to stop manually or set the number of clicks in advance.

Step 03

Start from anywhere

Press the configured shortcut. Hide the window to the tray when you need the screen back.
